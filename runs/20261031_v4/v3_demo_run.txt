> Explain in three short paragraphs why LLM decoding on a GPU is memory-bandwidth bound.

LLM decoding on a GPU is memory-bandwidth bound because the vast amount of data required for decoding—such as token sequences, attention weights, and model parameters—exceeds the GPU's memory capacity. GPUs, while powerful in parallelism, have limited memory, which can lead to frequent memory accesses and data transfers, slowing down the decoding process.

The high memory bandwidth requirements of LLM decoding further exacerbate this issue. Decoding often involves large matrix operations, such as attention mechanisms, which require continuous data flow between memory and the GPU's memory interface. This constant data movement can bottleneck the GPU, especially when the data size exceeds the available memory.
